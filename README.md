# my_portfolio

A personal portfolio site for Subhadra Biswal showcasing data-analytics and data-science projects.

What’s included:
- Home / Hero section with profile, terminal-style data profiling animation, and CTAs
- About, Skills, Projects, Experience, Education, and Contact sections

Local preview:
1. Open `index.html` in your browser, or serve locally with a simple HTTP server:

```bash
# Python 3
python -m http.server 8000

# then open http://localhost:8000
```

Profile image notes:
- The hero photo frame is 110×110px in CSS. For sharp results on high-DPI screens, use a 2× source (220×220px).
- Place your image in `assets/` and update the `<img src="...">` in `index.html`.

Contact:
- Email: add your preferred contact address in the `#contact` section of `index.html`.
